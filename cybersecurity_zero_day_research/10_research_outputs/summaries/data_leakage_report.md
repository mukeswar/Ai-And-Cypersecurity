# Data Leakage Report

Dataset: CSE_CIC_IDS2018. Generated by `08_scripts/dataset_split/make_splits.py`. Split rule: within each (capture_day, original_label) group, chronological 70/15/15 cut by (timestamp, row_in_file). No shuffling.

| # | Check | Result | Action |
|---|---|---|---|
| 1 | Duplicate samples across train/test (model-facing feature vector) | 708,842 test rows duplicated a train/validation vector; 729,806 validation rows duplicated a train vector | removed from val/test (training untouched); counts per class in class_distribution.csv |
| 2 | Same flow in different splits (provenance key source_file+row_in_file) | each key assigned to exactly one split by construction (1:1 merge validated) | none needed |
| 3 | Temporal leakage within (day,label) groups | 0 ordering violations | none |
| 3b | Temporal leakage across continual-learning stages | stages use disjoint, strictly increasing capture days [['2018-02-14', '2018-02-15'], ['2018-02-16', '2018-02-20'], ['2018-02-21', '2018-02-22', '2018-02-23'], ['2018-02-28', '2018-03-01'], ['2018-03-02']] | none needed |
| 3c | Standard split vs. future data | standard split is chronological *within* each day/label, not globally; days after a test flow can appear in train for other days | use continual_learning stages for strictly forward-in-time evaluation |
| 4 | Label leakage | label columns (original_label, standardized_label, mapping_confidence, is_attack, is_unseen_family) are excluded from model_feature_list.csv | none needed |
| 5 | Feature leakage / target-derived features | all model features are published CICFlowMeter flow statistics (unit conversion only); none computed from labels | none needed |
| 6 | Dataset-specific identifiers | Flow ID, Src IP, Dst IP, Src Port, timestamp, source_file, row_in_file excluded from model features. destination_port IS a model feature and is a known shortcut risk in CIC datasets (attacks target fixed service ports) | report results with and without destination_port |
| 7 | Preprocessing leakage / normalisation on test data | no scaling, imputation or clipping applied to any split; train-only statistics in feature_stats_train_only.csv | fit any scaler/imputer on train only |
| 8 | Conflicting labels | 22,370 feature vectors carry >1 standardized label (410,770 rows) | kept; reported (irreducible error / label noise) |
| 9 | Within-split exact duplicates | train 2,805,391; validation 490,535; test 466,865 (before cross-split removal) | kept (not leakage); consider sample weighting |
| 10 | Zero-day scenarios | withheld families absent from train/validation (asserted below) | see zero_day/*/scenario.json |
| 11 | Single-feature shortcut screen | see 10_research_outputs/tables/feature_label_purity_train.csv (majority baseline 0.8307) | features with purity near 1.0 deserve scrutiny |
