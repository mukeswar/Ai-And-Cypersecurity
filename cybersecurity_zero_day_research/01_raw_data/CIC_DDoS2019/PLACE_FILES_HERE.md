# CIC_DDoS2019 — raw files pending

The official distribution page could not be reached from the collection environment
(egress policy) and/or requires the publisher's registration form, which was not bypassed.

1. Download the files from the official page listed in `02_raw_metadata/data_catalog.csv`
   (see `08_scripts/download/download_datasets.py` → MANUAL_SOURCES for the exact files).
2. Place them in this folder unchanged (do not rename, unzip into a sub-folder if zipped).
3. Run `bash 08_scripts/run_pipeline.sh`. Checksums, validation, cleaning and harmonisation are automatic.
